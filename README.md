# Cafe API

A cafe where users can log in they favorite cafe, and add a few informations like: can take calls; coffee_price; has_wifi; location etc.

## Features

- Add cafes
- Check random cafes
- Check all cafes 

## Technologies

- Python
- Flask
- SQLAlchemy
- Postman

## Installation

1. Clone the repository

```bash
git clone https://github.com/gustavodev6331/cafe-api.git
```
2. Install the dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python main.py
```
